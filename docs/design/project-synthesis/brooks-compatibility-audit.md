## Scope retained

Underlying NIFTY/BANKNIFTY, primary five-minute completed-bar interpretation, no new entries inside genuine tight ranges, inward edge rotations in established wide ranges, and provider-neutral continuity. Options, spot-volume/OI analysis, advanced countertrend scalping, automatic additions and new order styles remain excluded/deferred unless independently specified and authorized. Countertrend methods described in broad channels are covered as source knowledge, not enabled by this audit.

The strong-bar policy, mandatory two-closes assumption, fixed 2R gate, one-minute latency and data-aware session cutoff from prior replays are experiment conventions. None becomes a universal production requirement merely because it appeared in a previous trial.
