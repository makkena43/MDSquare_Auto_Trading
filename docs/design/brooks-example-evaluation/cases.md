# Brooks example development cases

Ten qualitative cases from two visually reviewed source charts. All are development cases with draft labels, not independent holdout evidence. Exact candles, option quotes and calibrated probabilities are unavailable. CANDIDATE means a conditional underlying idea, never execution readiness.

## T01 - breakout_pullback_long

Source: Trading Price Action Trends, figure 18.1, PDF page 329. Cutoff: **close of labeled bar 4**.

**Visible context:** An upward impulse has exceeded the earlier bar-2 high. The bull move has strengthened; a completed post-breakout test is not yet present.

**Expected decision:** WAIT. A breakout is visible, but this setup requires a pullback and resumption signal.

**Confirmation/entry:** Observe a pullback that preserves the breakout structure, then a bullish signal and a configured crossing above its high.

**Invalidation:** Return and sustained acceptance below the broken structure would undermine continuation.

**Stop reference:** No mature pullback structure exists yet for a precise stop; do not invent one.

**Target reference:** Use earlier visible highs or a configured impulse projection only after entry structure forms.

**Limits / future evidence to exclude:** Do not substitute a breakout entry for the enabled breakout-pullback ID.
