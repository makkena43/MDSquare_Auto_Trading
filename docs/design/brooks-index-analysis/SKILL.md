# Brooks index analysis

Version 0.13.0. One unified skill with a compact default workflow and progressively loaded Brooks references. Underlying analysis only; profitability and calibrated probability remain unverified.

## Default workflow

Use the [simple operating playbook](references/simple-operating-playbook.md). Respect supplied pending/open/closed episode state and preserve unchanged premises unless evidence warrants revision. Review supplied open trades first, then assess new opportunities through context → location → enabled sequence → one coherent stop/target → decision.

- Preserve the current parent swing and full correction; do not reset them from a small opposing bar, nested pause or late confirmation.
- No new entry inside genuine tight ranges. In established wide ranges assess supported inward edge trades. A directional flag is not automatically an independent range.
- Every setup, including breakout, needs context and room. Category off overrides child on; do not enable new families or relabel consumed opportunities.
- Use completed available evidence and a still-prospective trigger. No future pivots/labels, invented prices/probabilities, backfilled knowledge or retroactive fills.
- Protect the appropriate full correction/base/excursion; choose a supported causal target before calculating economics. Do not manufacture a ratio or treat every prior extreme as either always passable or always a veto.
- For open trades hold through normal corrections when the premise survives; review cited structural/objective failure under the supplied policy. Never widen stops, improvise partials/additions, or assert self-confirmed fills/closures.
- Unknown inventory is not flat. Data/state uncertainty prevents the affected conclusion, while known protection remains authoritative.

Return a short context/action, relevant setup/location, complete candidate or supplied original geometry, and controlling reason/discriminator. WAIT/SKIP contains no armable new plan. Do not print every principle, pattern or internal check each candle.
